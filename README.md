# MOS nvtop

MOS nvtop provides **built and packaged nvtop binary** for use within the MOS ecosystem.

This repository contains the **build scripts and packaging logic**
required to compile nvtop from upstream sources and package it for MOS.

---

## Overview

nvtop is built **from upstream source code** and packaged for integration into MOS.

No functional changes to nvtop itself are intended.  
The goal of this repository is to provide **consistent and reproducible nvtop packages**
for MOS installations.
